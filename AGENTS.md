# Инструкция для новой сессии в этой папке

Проект: **«Служебное расследование»** — детективная браузерная игра (офисный нуар, соло,
18+). Расследование ведётся только по документам: улики читаются, в прочитанном ищется
**зацепка** (выделенный фрагмент + направление проверки), по зацепке в дело поступают
новые материалы и люди, две улики сравниваются, в конце игрок выносит **постановление**.

Это файл-вход. Дальше — `docs/MECHANICS-V2.md` (как устроены зацепки и каркас, цифры
приёмки), `docs/PLAYBOOK.md` (как делается дело), `docs/MECHANICS.md` (механики и занятые
имена), `docs/OPS.md` (как запускать проверки в этом окружении), `docs/HANDOFF.md`
(передача между сессиями). Человеческое описание проекта — `README.md`.

## Три закона (нарушение = правка, это обсуждалось с пользователем)

1. **В материале нет авторских подытоживаний.** Никаких «Важно: …», «Обратите
   внимание», «Что это значит для дела», «Вывод для следствия». Бумага говорит
   канцелярским языком; мысль живёт в `reveals` связи, которую игрок добывает сам.
   `tools/validate.mjs` падает на маркерах толкования.
2. **Материалы поступают постепенно — через зацепку.** Часть материалов имеет `after`
   — это материал-основание. Стартовых (без `after`) — 5–14 на любое дело; новое дело
   без цепочки `after` считается незавершённым. С 07.11.2026 прочтения основания
   недостаточно: игрок должен выделить в тексте фрагмент и подать ходатайство по
   направлению, который действительно встречается в основании и в «адресе» детей
   (`title` + `where` + `keys` + `short` тегов). Направление строится по НАПЕЧАТАННОМУ
   корпусу (`DOCS.render`), а не по служебным полям: если слова направления игрок в
   тексте не видит, гейт `tools/check-hook.mjs` считает дело сломанным.
3. **Связи не влияют на оценку.** Формула: верные поля × 18 + близкие × 9 −
   подсказки × 6 + 10 за скорость. Не добавлять вес за количество найденных связей.

## Как сделать новое дело (кратко, детали в `docs/PLAYBOOK.md`)

Пункты 1—5 — это работа одной параллельной сессии («лэйна»). Пункты 6—8 делает
только шаг приёмки (`docs/PARALLEL.md`), в лэйне они запрещены.

1. Взять свой заказ: `briefs/case-NN.md` (он рисуется из `docs/ROADMAP.json`
    командой `node tools/make-briefs.mjs`). Там тема, профиль с числами, правда
    вечера, зарезервированные фамилии, города, фирмы и машины. Свой скелет:
    `node tools/new-case.mjs case-NN` → `cases-wip/case-NN/`.
2. Сначала `cases-wip/case-NN/DESIGN.md` — канон вечера: что случилось на самом
   деле, хронология по минутам, roster людей, карта материалов по нормам своего
   профиля, план связей, ответы формы сдачи. **Потом** код.
3. Восемь файлов по образцу `cases/case-07` (он самый свежий): `01-core.js`,
   `02..06-evidence.js`, `07-links.js`, `08-final.js`. Глобальная переменная
   `root.CASENN`, в конце `08-final.js` — `registerCase(C)`.
4. `node tools/check-case.mjs case-NN` — до зелёного состояния. Тулза не трогает
   входные html и чужие дела, поэтому ею пользуются три сессии сразу. Дополнительно
   `node tools/check-lookalike.mjs cases-wip/case-NN` после каждой крупной записи.
5. Прогнать глазами цепочки: `node tools/map-case.mjs case-NN` работает только
   после приёмки; в лэйне волны и глубину показывает `check-case.mjs`.
6. **(шаг приёмки)** Перенести `cases-wip/case-NN` в `cases/case-NN` и вписать
   8 тегов `<script src="cases/case-NN/0X-….js">` во входной html своего контура —
   `corp_game.html` (дела № 1–20) либо `Lai_CO.html` (продажное дело по охране труда) — между
   `js/00-store.js` и `js/10-docs.js` (порядок: `00-store` → теги дел по номерам →
   `10-docs` → `15-hook-engine` → `20-app`).
7. **(шаг приёмки)** `node tools/check.mjs` — до зелёного состояния, включая
   `isolation.mjs` (имена и топонимы не должны повторяться в других делах), затем
   `node tools/map-case.mjs case-NN`, обновление `README.md` и `docs/MECHANICS.md`
   (§1, §2, §3, §3.1), удаление черновика из `cases-wip`.
8. Пользователю — плейтест. Дело не считается готовым, пока оно не пройдено.

## Как принимать правки движка (не дел)

Движок правится только по явной просьбе пользователя. Порядок приёмки — такой:

1. `node tools/check.mjs` → exit 0 (8 гейтов). Это судья; `check-css.mjs` всегда exit 0,
   его вывод читаем глазами (каждый класс из js обязан быть в `assets/styles.css`).
2. `node tools/live/run.cjs tools/live/gate.cjs` — то же самое с записью отчёта в
   `tools/live/out/chk8.txt` (в PowerShell кириллица в консоли ломается, поэтому
   отчёты читаем файлами).
3. Живой прогон: `node tools/live/run.cjs tools/live/play.cjs`, затем
   `node tools/live/summarize.cjs` и читать `tools/live/out/p2.txt`. Ожидание: 7 фаз
   `FASE OK`, `read 38/38` по `case-01`, `не поступило (0)`, строк журнала «Ход» 24,
   переполнений 0, ошибок страницы 0. `run.cjs` вернёт `EXIT=0` и при падении фазы —
   читать `play.txt` на `FASE FAIL`.
4. Буквы не уплывают: `node tools/live/run.cjs tools/live/sweep.cjs` → 0 замечаний из
   128 экранов (2 темы × 4 ширины + эмуляция печати) в `tools/live/out/sweep.txt`.
   `play.cjs` и `sweep.cjs` убивают все процессы браузера и не запускаются параллельно.
5. Контент не потерялся: `node tools/live/silent-audit.cjs` (0 молчаливых потерь из 742
   материалов) и `node tools/live/logline-audit.cjs`.
6. Артефакты модели в русском тексте: `node tools/live/cjk-check.cjs <файлы>` → «OK — 0
   проблем» (ловит иероглифы, склеенную латиницу и ломаетя на плохом синтаксисе js).
7. Откат — `backup/engine-v2-before/` (копия движка до переделки механики, список md5 в
   `V2BEFORE.md5.txt`). Личный приватный git — заводить можно (решение 07.11.2026), в индексе нет файлов рабочей среды.

## Правила, которые экономят часы

- **Имена и названия вымышленные и уникальные между делами.** Реестр занятых —
  `docs/MECHANICS.md`; проверка автоматом в `tools/isolation.mjs`.
- **Никаких изображений-фотографий.** Все 41 «кадр» — векторные `svg`-схемы в
  `cases/case-NN/assets/` (у черновика — в `cases-wip/case-NN/assets/`). Генерация
  картинок в этом окружении недоступна.
- **После каждой крупной записи русского текста** проверять артефакты модели:
  склеенная латиница `[а-яёА-ЯЁ][A-Za-z]{2,}` и иероглифы. Команды — `docs/OPS.md`;
  в лэйне — `node tools/check-lookalike.mjs cases-wip/case-NN`.
- Не предлагать пользователю правки, которые ломают пройденные дела, без явного
  предупреждения.
- Пользователь пишет по-русски — отвечать по-русски, без герундия и без простыней.
- Вопросы задавать только инструментом `question`: веб-сессии octto/браузера
  пользователь не видит.
