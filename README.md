# Служебное расследование

Детективная браузерная игра в жанре «офисный нуар»: расследование корпоративного
убийства по документам. Никаких движков, сборки и зависимостей — папка открывается
двойным кликом по `index.html`.

Возрастные метки: **16+** и **18+** по делам (в 18+ — подробные протоколы СМЭ, труп,
оружие).

---

## Запуск

```
Двойной клик по index.html
```

или, если нужен именно браузер по умолчанию другой:

```
start "" index.html
```

Работает по протоколу `file://`. Важно: скрипты подключены
классическими `<script src>` (не ES-модулями) — иначе браузер блокирует загрузку
файлов с диска из-за CORS.

### Что изменено по итогам первого плейтеста (дело № 1)

1. **Убраны все подытоживающие строки** в конце документов — «Важно: …», «Что это
   значит для дела», «Вывод: …». 73 правки по трём делам; мысль, которая жила в
   такой строке, перенесена в `reveals` соответствующей связи — ничего не потеряно.
   Запрет закреплён в валидаторе и действует для всех будущих дел.
2. **Материалы поступают постепенно** (`after` / `afterLink`), а не вывалены сразу:
   сейчас 558 материалов из 742 открываются по ходу расследования.
3. **Связи больше не влияют на оценку** — только пять полей заключения, подсказки и
   скорость.

## Как играть

1. В меню выбрать дело, прочитать брифинг.
2. Слева — список материалов (категории, поиск, отметка «не прочитано»). Центром —
   читалка документа: листать `←` `→`.
3. **Зацепка — главный способ двигать дело.** В документе выделяется фрагмент текста
   (номер, фамилия, время, странность) → кнопка «Взять в разработку» (`J`) → из
   предложенных направлений выбирается одно, при желании указывается, кого вызываем.
   Это ходатайство: если направление действительно следует из текста, следователь его
   принимает и в дело поступает материал. Направление, которого в тексте нет, даёт
   отказ «Оснований не вижу» — цитата при этом не теряется.
4. Два материала можно положить в **сравнение** (клавиша `L` или кнопка «Сравнить»
   под списком) — если между ними есть связь, игра её выдаст и отметит подозрение
   или алиби у человека.
5. Справа — доска: **люди** (карточки, биография, «что говорит», отметки),
   **связи**, **ход** (журнал: что и почему поступило, кому отправлены повестки),
   **таймлайн** (строится сам из просмотренных документов с временем),
   **заметки** (сохраняются).
6. `H` — подсказка. Перед выдачей игра спросит подтверждение: подсказки удешевляют
   итог дела, но снимают тупик.
7. Сдать дело — кнопка «Сдать» (или `F`): сначала шлюз-подтверждение с недоследованными
   хвостами, затем отдельный экран **«Постановление»** — бланк из 5 полей (кто, где,
   когда, чем, мотив) с подписью. После подписания — вердикт, разбор по каждому полю
   и полная реконструкция вечера; бланк можно распечатать.

### Материалы поступают постепенно — через зацепку

Дело не вываливается на игрока целиком. В списке лежат только те документы, которые
следствие уже успело истребовать: ~10 стартовых (осмотр, судмедэкспертиза, первые
объяснения, дежурные журналы). Остальные приходят **только после принятого
ходатайства** по направлению, которое видно в тексте прочитанного: слова направления
сверяются с напечатанным корпусом документа-основания и с «адресом» детей
(`title` + `where` + `keywords` + короткие теги людей), а не со служебными полями.
Триггер — осознанная находка игрока, а не факт прокрутки страницы.

Список в левой колонке сгруппирован по движению дела: **Входящие** (лежали в папке),
**В работе** (по зацепке запрошены, ещё не пришли), **Приобщённые** (в деле).
Прочитанное из папки не исчезает.

Люди выходят на доску волнами — как только фамилия упоминается в прочитанном;
протокол допроса приходит после **повестки**, а не сразу. Кнопка «Вызвать» есть
только у тех, кого уже можно вызвать.

Сколько закрытых материалов осталось, видно под списком. Кнопка там же —
**«Ходатайство о выемке всего»**: снимает все блокировки разом, но стоит как три
подсказки. Это страховка от тупика, а не обходной путь: 5–14 стартовых материалов
плюс цепочка `after` у остальных настроены так, что дело проходится без неё.
Для 10 материалов по всем делам словесного мостика в тексте нет (их не о чем
просить) — они доходят сами, когда прочитано основание.

### Что влияет на итоговую оценку

Только то, что игрок назвал в заключении:

```
5 верных полей × 18  +  близкие ответы × 9  −  подсказки × 6  +  10 за скорость
```

Количество найденных связей и процент прочитанных документов на оценку **не влияют**.
Связи — инструмент игрока, а не условие победы: в деле можно разобраться и без
«сравнения», просто читая бумаги. Игра всё равно покажет, сколько пар вы не связали,
— но как справку, а не как потерю баллов.

Прогресс (прочитанное, связи, заметки, вердикт, часы) лежит в `localStorage` под
ключом `sr.save.v1`. Кнопка «Стереть прогресс» в меню чистит всё.

**Сценарий «один экран на компанию»:** игра рассчитана на то, что файл открыт на
одном экране, дело ведёт один человек, остальные подсказывают. Крупная типографика,
навигация клавиатурой, шлюзы спойлеров — чтобы ведущий не спойлерил сам себя.

### Вывести на телевизор

Вариант 1 — **экран компьютера на телевизоре** (рекомендую, ничего не нужно открывать
в сети): HDMI-кабель либо беспроводной дублирование/проекция `Win + K`. Затем
`F11` — полный экран. Игра работает по-прежнему с клавиатуры и мыши компьютера,
шрифт и вёрстка ровно те же, что на мониторе.

Вариант 2 — **локальный сервер**, если телевизор со своим браузером и он в той же сети:

```
node tools/serve.mjs            # порт 8765, выведет адрес вида http://192.168.x.x:8765/
node tools/serve.mjs --port 9000
```

На телевизоре в браузере ввести адрес из вывода. Сервер только отдаёт файлы папки и
ничего не пишет. Прогресс при этом хранится в `localStorage` **браузера телевизора**,
то есть отдельно от прогресса на компьютере.

Важно про сеть: сервер слушает `0.0.0.0`, то есть доступен всем устройствам сегмента.
Держать его запущенным в корпоративной сети не стоит (лишний откры порт на рабочей
машине + его зарезолвит файрвол). Останавливать `Ctrl+C`. Для домашнего Wi-Fi —
нормально; если входящие блокируются, временно разрешить порт в брандмауэре.

### Горячие клавиши

| Клавиша | Действие |
|---|---|
| `←` / `→` | предыдущий / следующий материал |
| `Пробел` | фокус в заметки |
| `L` | сравнить два материала в лотке |
| `J` | взять выделенный фрагмент в разработку (ходатайство) |
| `H` | подсказка |
| `B` | доска справа (люди / связи / время / заметки) |
| `T` | светлая / тёмная тема |
| `F` | полный экран |
| `?` | список клавиш |
| `Esc` | закрыть окно / назад |

Раскладка: русские дубли (`д`, `р`, `и`, `е`, `а`) тоже работают.

### Стереть прогресс

- **Всё сразу**: на стартовом экране внизу кнопка «Стереть прогресс» — спросит
  подтверждение и обнулит прочитанное, связи, подозрения, заметки, время и вердикты
  по всем делам.
- **Одно дело**: после сдачи дела, в окне вердикта, кнопка «Играть это дело заново» —
  сбрасывает только его, остальные остаются как были.
- **Вручную, если игра не открывается**: прогресс живёт в `localStorage` браузера под
  ключом `sr.save.v1`. `F12` → вкладка «Application» (Firefox — «Хранилище») →
  Local Storage → файл `index.html` → удалить ключ `sr.save.v1`.

Прогресс привязан к браузеру и к пути папки: в другом браузере, в режиме инкогнито
или после переноса папки в другое место игра начнётся с чистого листа.

#### Материал (улика)

```js
{
  id: 'e07',
  cat: 'Камеры',            // категория в левой колонке
  title: 'G-04, контейнерная площадка',
  kind: 'cctv',             // см. ниже
  at: '23:03',              // 'ЧЧ:ММ' -> попадёт в таймлайн; null если времени нет
  where: 'Камера G-04, внутренний двор',
  tags: ['roshchin'],       // ТОЛЬКО id людей, названных в документе
  keys: ['огнетушитель ОП-5', 'карта С-0007'],  // «следы»: предметы, места, коды, суммы
  after: ['e19'],           // поступит, когда прочитан ЛЮБОЙ из списка
  afterLink: ['c04'],       // либо когда найдена связь (по желанию)
  img: null,                // путь к файлу, либо null -> текстовая заглушка кадра
  doc: { /* зависит от kind */ }
}
```

Без `after`/`afterLink` материал — стартовый: он в списке с самого начала.

`kind` → что рисует `js/10-docs.js`:

| kind | Как выглядит | Поля `doc` |
|---|---|---|
| `act`, `doc`, `legal`, `ticket`, `note`, `order`, `ledger` | бумажный бланк | `org,num,date,title,meta[[k,v]],kv[[k,v]],table{cols,rows},body[{h|p|list|kv|table|quote|note}],sign{pos,name},stamp{text,tone},hand` |
| `table` | бланк с ведомостью | `org,num,date,title,note,table,stamp` |
| `talk` | протокол допроса «вопрос — ответ» | `org,num,date,title,meta,qa[{q,a}],note` |
| `email` | экран почты | `bar,from,to,cc,date,subject,attach[],body` |
| `chat` | экран мессенджера | `bar,who,msgs[{who,text,time,me,day}]` |
| `photo`, `cctv`, `shot` | снимок / кадр наблюдения | `img,cam,ts[],ph,cap,meta[[k,v]]` |

Правила, которые держат дело рабочим:

- Внутри текстов намеренно есть `<b>`, `<i>`, `<u>` — рендерер их **не экранирует**.
  Отсюда: в данные нельзя вставлять сырой текст из внешних источников.
- **Никаких подытоживающих строк внутри материала.** Запрещены «Важно: …»,
  «Внимание: …», «Обратите внимание», «Ключевой момент: …», «Что это значит для
  дела», «Следовательно, алиби», «Вывод для следствия: …» и прочая авторская
  расшифровка в конце документа. Материал — это первичная бумага: в ней есть
  подписи, штампы, протокольные формулировки и формальные выводы самой экспертизы
  («смерть наступила от…»), но нет ответа на вопрос «что из этого следует». Мысль
  живёт в `reveals` связи — там, где игрок сам её добывает, сопоставляя два
  документа. Правило постоянно и для всех будущих дел; `tools/validate.mjs` ловит
  маркеры и падает с ошибкой.
- `tags` — строго «кто назван». Если человек в документе не назван, но это он
  (силуэт на кадре) — это идёт в `keys`, иначе карточка человека спойлерит решение.
- `keys` — то, за что цепляется «близко, но вывода нет»: общий предмет, место, код,
  карта, сумма. У каждого материала должны быть непустые `tags` **или** `keys`.
- Цепочка `after` обязана быть **достижимой**: валидатор проигрывает симуляцию
  «игрок дочитывает всё доступное» и падает, если хоть один материал остался
  недостижимым. Стартовых материалов — от 5 до 14, глубина цепочки — до 7 шагов.

#### Связь

```js
{
  id: 'c04',
  a: 'e10', b: 'e11',                     // id материалов, порядок не важен
  reveals: 'Строка 41823 есть в бэкапе…', // что игра выдаёт игроку
  flags: { roshchin: 'watch', solovyov: 'clear' }  // watch | clear
}
```

Поля `reveals` обязательны (минимум 40 знаков), `flags` — только id людей из
`persons`. Связи, которые **снимают** подозрение, важны не меньше обвиняющих: в
деле № 1 их четыре (Тумина, Ремезова, Хайруллин, Соловьёв).

#### Форма сдачи

`C.objective.fields` — ровно 5 полей: `culprit`, `place`, `window`, `weapon`,
`motive`. У каждого: `options[[value,label]]`, `correct`, `explain` (обязательно),
необязательно `near` (частично верные ответы, например «опцион» вместо «страх
разоблачения»).

## Проверки

```
node tools/check.mjs            # все гейты одной командой (exit 0 = принято)

# или по отдельности:
node tools/validate.mjs         # целостность данных: id, ссылки, теги, поля формы
node tools/check-hook.mjs       # механика зацепок: направления, поступления, волны людей
node tools/check-dom.mjs        # каждый $('id') из движка есть в index.html
node tools/check-css.mjs        # каждый класс из разметки описан в стилях
node tools/check-lookalike.mjs  # артефакты в текстах: латинские слова и иероглифы
node tools/check-svg.mjs        # схемы: баланс тегов, viewBox, кавычки в атрибутах
node tools/isolation.mjs        # дела не ссылаются друг на друга
node tools/smoke.mjs            # все скрипты грузятся, все 38 материалов рендерятся
node tools/check-case.mjs case-01   # одно дело целиком
```

`check-hook.mjs` — гейт механики: на старте открыты только корневые материалы, прочтение
доступного не открывает ничего нового, по каждому направлению слова сверяются с
НАПЕЧАТАННЫМ корпусом основания (то, чего игрок не видит в тексте, направлением не
считается), ложное направление обязано дать отказ, «идеальный игрок» закрывает 100 %
материалов, связей и лиц во всех делах.

### Живые проверки (только что приняты)

```
node tools/live/run.cjs tools/live/gate.cjs          # сборка гейтов -> out/chk8.txt
node tools/live/run.cjs tools/live/play.cjs          # CDP: 7 фаз реального прогона дела № 1
node tools/live/summarize.cjs                        # срез out/play.txt -> out/p2.txt
node tools/live/run.cjs tools/live/sweep.cjs         # CDP: 2 темы x 4 ширины + печать, 128 экранов
node tools/live/run.cjs tools/live/silent-audit.cjs  # ни один материал не потерялся в рендере
node tools/live/cjk-check.cjs <файлы>                # иероглифы/латиница в русском тексте
```

`play.cjs` и `sweep.cjs` запускают браузер с удалённым отладчиком и убивают все его
процессы — вместе их не гонять. `run.cjs` печатает только `EXIT=`; содержимое читать
в `tools/live/out/`.

Валидатор ловит: дубликаты id, ссылки связей на несуществующие материалы, `flags`
с неизвестным человеком, материалы без «следов», пары без пересечений, значения
`correct`/`near` вне списка опций, изолированные улики, отсутствующие файлы
изображений. Плюс правила сценария: **подытоживающая строка в материале** (см.
«Правила, которые держат дело рабочим») — ошибка; **недостижимый материал** в
цепочке `after` — ошибка; меньше 5 или больше 14 стартовых материалов — ошибка;
цепочка глубже 7 шагов — предупреждение. Ошибки — `exit 1`; предупреждения — текст
в консоль, но не падение.

`check-lookalike` — страховка от брака генерации: в русскую фразу иногда
вывается английское слово либо символ чужой письменности. Смотрит и данные, и код,
и документы; игнорирует `код в обратных кавычках` и блоки ```кода```; для
технических `AGENTS.md` и `docs/` оставляет только проверку на чужие письменности.

## Как добавить дело

1. Скопировать `cases/case-01/` в `cases/case-02/`, переименовать `root.CASE01` →
   `root.CASE02` во всех файлах папки, поменять `id`, `num`, заголовок.
2. Перезаписать содержимое: 8 файлов по схеме выше. Порядок подключения — по
   возрастанию номера, `08-final.js` последним (он вызывает `registerCase`).
3. Разложить материалы по времени поступления: 5–14 стартовых (осмотр, экспертиза,
   дежурные журналы, первые объяснения), у остальных — `after` на документ, который
   даёт основание их истребовать. Проверить себя: `node tools/validate.mjs` печатает
   «поступление материалов: шаг 0: … » и падает, если хоть один материал недостижим;
   `node tools/check-hook.mjs` — что до каждого закрытого материала есть направление,
   которое игрок видит в тексте основания (плюс волны людей и повестки).
4. Вычитать материалы на предмет подытоживающих строк (см. «Правила…») — каждая
   такая строка снижает игру до чтения готовых ответов. Мысль переносится в `reveals`
   связи.
5. Дописать теги `<script src>` в `index.html` (после `js/00-store.js`, до
   `js/10-docs.js`).
6. `node tools/check.mjs` — должно быть «все проверки пройдены».
7. Пройти дело целиком руками (см. «Плейтест» ниже), иначе оно не считается готовым.

Тиражирование движка не нужно: меню само рисует все зарегистрированные дела.

### Плейтест одного дела (обязательно, ~45 мин на проход)

## Известные ограничения

- Один сейв в браузере, без экспорта. Параллельно играть с двух устройств нельзя.
- Бейдж «новое» живёт до перезагрузки страницы: если закрыть игру и зайти снова,
  ещё непрочитанные материалы останутся в списке, но без пометки.
- Движок не умеет ветвящийся диалог: допрос — статичный протокол `q/a`.
- Нет проверки «игрок сам сформулировал вывод»: сравнение работает только по
  заранее заданным парам из `07-links.js`.
