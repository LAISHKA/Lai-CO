Формат: один файл = один заказ. Пишет бизнес-сессия, исполняет технарь в своей сессии.
**Технарь не берёт заказ из головы или из чата — только отсюда.**

**только** заказы слоя доставки T1–T8 (и T9, когда бизнес-сессия откроет заказ на SDK). Новые механики, звук, анимация, сервер, аккаунты, кооп,
сохранение между устройствами, перевод, магазин — не делать, пока не будет строк в `../STATE.md`
типа «письма отправлено: 60, ответов: 3». Дело № 21 в этот запрет больше не входит: оно принято в
публичный тайтл 08.11.2026 и правится по указанию владельца (T7).
