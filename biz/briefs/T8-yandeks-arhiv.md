# T8 — починить архив для Яндекс Игр

**Часов: 0,5–1.** Заказ от 09.11.2026, устное решение владельца: «пусть технарь починит архив».

## Зачем

Сейчас `dist/demo-ot.zip` не примут. Причина одна: в корне архива лежит `Lai_CO.html`, а
требование платформы (пункт 1.22, редакция 27.10.2026) — **`index.html` в корне архива**.

Разделение на два входа (`Lai_CO.html` для продажи, `corp_game.html` для тимбилдинга) остаётся
как есть. `index.html` — это не третья версия игры, а **имя файла внутри архива**. Ничего не
сливать, ничего не переписывать в логике.

## Что сделать

1. Сделать сборку `dist/yandex.zip` из публичной ветки: движок + дело 21 + `assets`.
   В корне архива — `index.html` (содержимое = текущий `corp_game.html`, если он собирает
   все дела, либо `Lai_CO.html`, если на площадку решено нести одно короткое дело — выбрать по
   факту и написать в `NOTE.txt`, какой вариант собран).
2. В этой сборке **публичный режим должен быть включён в файле**, а не через `?public=1`:
   журнал не спрашивает ФИО и группу на чужой площадке. То есть `window.SR_PUBLIC = true` рядом
   с подключением `js/30-report.js`.
3. Убрать `NOTE.txt` из архива (или переименовать в `README.txt`) — служебные файлы модератор
   читать не обязан.
4. Имена файлов и папок внутри архива: латиница, без пробелов (тот же пункт 1.22). Проверить
   `assets/` и svg.
5. Размер в разархивированном виде ≤ 100 МБ (пункт 1.21). Текущий zip — 597 КБ, запас огромный.
6. Убрать из публичной сборки всё, что нельзя: 18+, трупы, эротику, материат (пункты 8.3.5,
   8.2.4), и **любые внешние ссылки** (пункт 8.4.2 — нельзя даже в текстах: ни на сайт, ни на
   «корпоративную версию», ни на Telegram). Если ссылка на продажу стоит в `corp_game.html` —
   в архив она не попадает.
7. Проверить, что в коде нет абсолютных URL на `games.s3.yandex.net` (пункт 1.7).

## Чего НЕ делать в этом заказе

- Не встраивать SDK Яндекс Игр, рекламу, `LoadingAPI.ready()`. Это отдельный заказ T9 (T7 занят
  сжатием дела № 21), он
  появится только когда будет решение нести тайтл на площадку всерьёз. Без SDK архив не
  опубликуется (пункт 1.1, 1.12) — но сейчас задача в другом: чтобы сборка была правильной формы.
- Не резать контент дела 21 дальше.
- Не трогать `js/00-store.js`.
- Не создавать 22-е дело.

## Приёмка (четыре проверки, выполняются командами)

```powershell
Add-Type -AssemblyName System.IO.Compression.FileSystem
$z=[IO.Compression.ZipFile]::OpenRead("$PWD\dist\yandex.zip")
"index.html в корне: " + [bool]($z.Entries | Where-Object { $_.FullName -eq 'index.html' })
"плохие имена: " + (($z.Entries | Where-Object { $_.FullName -notmatch '^[\x21-\x7E]+$' }).Count)
"байт в архиве: " + [int](($z.Entries | Measure-Object Length -Sum).Sum)
"ссылки наружу в index.html: " + ([regex]::Matches([IO.File]::ReadAllText("$PWD\index.html"),'href="http')).Count
$z.Dispose()
```

Готово = первые три строки дали `True / 0 / число < 100 000 000`, архив открывается двойным
щелчком и дело проходится до постановления. Плюс: при открытии из архива **не** появляется окно
«Кто вы» (публичный режим включён файлом).

## Что после этого

Архив лежит и ждать не может: модерация 3–5 рабочих дней. Но **подавать его надо после**
двух чужих прохождений (10.11) — иначе мы чиним витрину магазина, которого ещё не открывали.
