## 2. Что принято 07.11 по движку

Механика (`js/15-hook-engine.js` + перешитая `js/20-app.js`):

- Новый материал поступает ТОЛЬКО после зацепки в уже открытом: игрок выделяет фрагмент →
  «Взять в разработку» (`J`) → выбирает направление проверки. Прокрутка и простое открытие
  ничего не открывают.
- Направление принимается по **напечатанному** корпусу основания (`DOCS.render`) и «адресу»
  детей (`title` + `where` + `keys` + `short` тегов людей). Если слов нет в тексте, который
  игрок реально читает, — ходатайство отклоняется: «Оснований не вижу» (ложные направления
  ничем не отличаются от настоящих: тот же формат счётчика и перемешанный порядок).
- Люди выходят волнами: фамилия должна быть упомянута в прочитанном. Протокол допроса
  (`kind: 'talk'`) приходит только после повестки — это отдельное действие (`button.summon`).
- Вкладка «Ход» (`renderProtocol()`) — журнал: что и по какой зацепке поступило, кому вручена
  повестка, где был отказ.
- Клапаны, чтобы механика не заперла дело: тихий автоклапан (10 материалов на 20 дел — тем,
  где словесного мостика нет физически) и «Ходатайство о выемке всего» за 3 подсказки
  (`st.revealAll`, входит в штраф оценки).
- Прочитанное не исчезает из папки (`availableSet` держит прочитанные id), папка сгруппирована
  «Входящие / В работе / Приобщённые».

Каркас (серьёзные экраны): корешок папки дела (`.folder-tab`), гриф на листе (`#doc-grif`:
дело и дата, `л. д. N / M`, «экз. № 1») с штампом по основанию приобщения (`#doc-stamp`:
ВХОДЯЩИЙ / ПРИОБЩЕНО ПО ХОДАТАЙСТВУ / ПРОТОКОЛ ДОПРОСА / ИЗ МАТЕРИАЛОВ ДЕЛА), «стол
следователя» (`.col-reader.desk`), и **«Постановление» — отдельный экран `#view-verdict`**
(бланк с полями и подписью) вместо всплывающего окна. Действия этого экрана — `[data-vact]`:
`back`, `send`, `print`, `again`, `menu`.

Три бага, найденные живым прогоном и починенные (не «возвращать»): `pendingDirections()`
больше не закрывает направление после первой зацепки с человеком; `availableSet()` держит
прочитанные материалы; описание кадра (`doc.ph`) печатается и когда снимок загрузился
(`.shot-desc` в `js/10-docs.js`).

## 8. Болячки среды (Windows PowerShell 5.1 + кириллица)

- `||` не поддерживается, разделитель `;`. В команде shell нельзя `!` и `|` в кавычках —
  писать `.cjs`-файл.
- Вывод node с кириллицей через консоль = mojibake; редирект `> file` = UTF-16. Правильно:
  `node tools/live/run.cjs <скрипт>` — пишет UTF-8 в `tools/live/out/run-out.txt` и печатает
  только `EXIT=`. **`EXIT=0` не гарантирует успех фаз** — читать отчёт на `FASE FAIL`.
- `grep`/`Select-String` по кириллическому паттерну не матчит — фильтровать ASCII-паттернами;
  `grep` с `include: "cases/**/*.js"` внутри `cases` даёт «No matches» — указывать файл.
- В русский текст лезут иероглифы и латиница — даже у ассистента (случаи 07.11: три CJK-знака
  в русском комментарии и склейка «не» с заглавной в середине слова). После каждой крупной
  русской правки — `node tools/live/cjk-check.cjs <файлы>`; строки с CJK инструмент `edit` не
  матчит, такие места чистить скриптом.
- `tools/check-lookalike.mjs` режет необычные символы: не использовать `⇒`, `⤢`, `∈`
  (в том числе в markdown); можно `→`, `·`, `≥`, `×` и эмодзи.
- `edit` требует точных отступов; injected-копия `AGENTS.md` отличается от файла на диске —
  всегда читать файл перед правкой.
- Одноразовые скрипты предыдущих сессий лежат в `%LOCALAPPDATA%/Temp/opencode/`
  (`accept.cjs`, `index_insert.cjs`, `findquote.cjs`, `ident.cjs`, `form1113.cjs`,
  `surcheck.cjs`, `collide.cjs` — у последнего пункт «артефакты» сломан, не верить). Temp
  чистится между сессиями: всё нужное уже перенесено в `tools/live/`.
