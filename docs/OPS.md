# Операционка: как работать в этом окружении

Это то, что стоит несколько сессий и несколько испорченных файлов. Всё проверено на
машине пользователя (Windows, PowerShell без `&&`, Node доступен, репозитория git нет).

## Запуски и проверки

```
node tools/check.mjs                 # все семь проверок, таймаут 300–400 с
node tools/validate.mjs              # целостность данных + достижимость after
node tools/map-case.mjs case-05      # карта поступления материалов по одному делу
node tools/smoke.mjs                 # загрузка всех скриптов и рендер всех улик
node tools/isolation.mjs             # повторы фамилии и топонимы между делами
node tools/serve.mjs                 # http://<ip>:8765 — играть с телевизора
```

Полный прогон занимает минуту-две. `check.mjs` включает `validate`, `smoke`,
`check-dom`, `check-css`, `check-lookalike`, `check-svg`, `isolation`.

## Консоль ломает кириллицу — выводим в файл

Прямой вывод русских строк из PowerShell нечитаем (cp866). Перенаправление `> file`
пишет UTF-16, и инструмент `read` такой файл не берёт. Правильный способ:

```
node -e "const{execFileSync}=require('child_process');const fs=require('fs');let o='';try{o=execFileSync('node',['tools/check.mjs'],{encoding:'utf8',maxBuffer:1e8})}catch(e){o=(e.stdout||'')+'FAILED\n'+(e.stderr||'')};fs.writeFileSync('%LOCALAPPDATA%/Temp/opencode/check.txt',o);console.log('len='+o.length)"
```

потом прочитать `Temp\check.txt` инструментом `read`.

PowerShell вызывать полным путём и только из `.ps1`-файла:

```
C:\Windows\System32\WindowsPowerShell\v1.0\powershell.exe -NoProfile -ExecutionPolicy Bypass -File "<...\script.ps1>"
```

Однострочники с `$_`, `$var`, `«…»`, `—` или `node -e` с юникодом inside кавычек
портятся на раз. Длинную логику — в `.mjs` в `%LOCALAPPDATA%\Temp\opencode\`
и запускать файл. `Set-Content -Encoding UTF8` дописывает BOM — снимать (`slice(3)`).
`cmd /c` запрещён политикой окружения.

## Мелочи оболочки, на которые спотыкались

- PowerShell не понимает `&&` — команды разделять `;`.
- `Select-String` с русным шаблоном и русский вывод из node в консоли дают кашу.
  Данные брать из файлов, которые пишет сам прогон (`Temp/run5.txt`, `Temp/check.txt`),
  а не из вывода терминала.
- Помощники-скрипты (флаги, пары, длины `reveals`, карта материалов) писать в
  `%TEMP%/opencode` расширением `.cjs` и всегда выводить результат в файл.
- Патчер обязан подставлять полный путь: директория + имя файла. Из-за имени файла без
  пути в корне проекта уже появлялись двойники.
- Скан «латиница внутри русских строк» (`Temp/latin-all.cjs`) проверяет только
  строковые литералы с кириллицей. Легальные срабатывания: маски телефонов `4xx-xx`,
  серии `Г-1xx`, `Б-01`, римская `III` в отчётных периодах.
- После любой вставки блока в конец массива перечитать два соседних блока: потерянный
  отступ и потерянная запятая — типовые последствия.

## Обязательная вычитка после крупной записи текста

Модель в длинном русском тексте иногда оставляет **иероглифы** и **приклеенную
латиницу** (`метeoсправка`, `МелкиеTruthy совпадения`, `наOther документы`), а также
недоказанные кальки. Штатный `check-lookalike` смотрит `.js`, `.html`, `.css`,
`README.md`, `AGENTS.md` и `docs/`: в `cases/` и `README.md` он ловит и английские
слова в русской прозе, а для `AGENTS.md`/`docs/` — только символы чужих
письменностей (технические термины там законны). Примеры выше намеренно в обратных
кавычках: сканер их пропускает, а в обычном тексте они считались бы браком. Поэтому
после каждого большого `write`:

```
node --check cases\case-05\03-evidence.js          # синтаксис
node %LOCALAPPDATA%\Temp\opencode\scan-glue.mjs cases\case-05 docs AGENTS.md
```

`scan-glue.mjs` (лежит в Temp, при необходимости пересоздать) ищет склейку
`[а-яёА-ЯЁ][A-Za-z]{2,}|[A-Za-z]{2,}[а-яёА-ЯЁ]` и диапазоны CJK
`[\u3000-\u303F\u3400-\u4DBF\u4E00-\u9FFF\uFF00-\uFFEF]`. Латинские слова в русской
фразе он не ловит намеренно — они легальны в коде, в прозе их ищет `check-lookalike`.

Типовые ошибки данных, которые ловит только `node --check`: незакрытый `body:[` перед
`sign:`/`stamp:`, лишняя `}` после `note:'…' }`, `kv:[` закрытый через `},`,
пропущенная закрывающая кавычка, `)` вместо `]`.

## Массовые правки текстов

Не править 38 материалов вручную. Писать скрипт-патчер: явная таблица операций
`{f: файл, ln: номер строки, op: 'del'|'sub'|'cut', a: было, b: стало}`, выполнение по
файлам с сортировкой строк по убыванию, отчёт с `MISS`/`BOLD!` для непрошедших
операций, и обязательная проверка баланса `<b>` перед заменой. Идемпотентность —
обязательное свойство: повторный запуск не должен портить данные (сначала снести
старое, потом вставить новое). Так делались `patch-interp.mjs` (73 правки выжимок) и
`patch-after.mjs` (87 вставок `after`).

Блоки данных в `cases/**/*-evidence.js` занимают одну строку, поэтому удаление строки
безопасно: висячая запятая в массиве легальна.

## Символы в текстах дел

Разрешены: `² ³ ° ± × ÷ – — … «» № µ Ω ⌀ ‰` и эмодзи из `OK_EMOJI`
(`check-lookalike.mjs`). Запрещены: неразрывный дефис `U+2011`, надстрочные буквы,
вложенные кавычки `„“`. В `README.md`/`.md` нельзя писать латинское слово между двумя
кириллическими — сканер поднимет ошибку; идентификаторы оформлять обратными кавычками.

## Архив и отправка

Сборка демо-архива — `node tools/pack-demo.mjs --cases case-21 --out dist/demo-ot.zip --note "…"`.
Инструмент берёт входной html того контура, где лежит первое запрошенное дело (для дела № 21 это
`Lai_CO.html`; теги невыбранных дел вырезаются), кладёт в zip методом STORE (без сжатия — открывает
любая Windows): `Lai_CO.html`, `NOTE.txt`, `js/`, `assets/`, `cases/case-21/`. Проверка состава:
`Expand-Archive` во временную папку; SHA-256 печатает `Get-FileHash` — цифры вписываются в
`outreach/REESTR-PISEM.md`. Старый `Temp\build-zip.ps1` (полный репозиторий с `index.html`) не используется.

Почта: рассылка — только вручную с личной почты. Рабочий домен работодателя не используется
ни для писем, ни для календаря, ни для задач (`biz/REDLINES.md`). Из агента — через COM
`send-mail.ps1 -Spec <json> -ConfirmSend`, спека и тело письма отдельными файлами
(русский в JSON, не в аргументах). Почтовые сервисы режут архивы с `.js`/`.html`, поэтому
письмо с билдом уходит на личный ящик адресата (адреса в репозитории нет). Клиент покажет окно «программа
пытается отправить сообщение» — нужен клик «Да», потому перед отправкой всегда
спрашивать разрешение пользователя.

Генерация изображений в этом окружении недоступна (недостаточно средств на аккаунте) —
все схемы рисуются руками в SVG.

## Чего не делать

- Не инитизировать git и не коммитить: workspace вне репозитория, доставка — файлы и zip.
- Не трогать `js/*` ради косметики: на движке работают три пройденных дела.
- Не править пройденные дела без явного согласия пользователя.
- Не использовать LetSpace и не ссылаться на чужие детективные бренд-названия.
